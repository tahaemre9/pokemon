Bu proje, Python ve `discord.py` kütüphanesini kullanarak geliştirdiğim eğlenceli bir Discord Pokémon botudur. Bot sayesinde rastgele Pokémonlar üretebilir, onları PokeAPI'den çekilen görselleriyle birlikte görüntüleyebilir ve hatta diğer eğitmenlerle kapıştırabilirsiniz! 🔥

---

## 🚀 Özellikler Neler?

* **Rastgele Pokémon Üretme (`!go`):** Kendi Pokémon'unuzu rastgele özelliklerle (Can, Güç) sisteme kaydedersiniz ve görseliyle birlikte ekrana gelir.
* **Pokémon Bilgileri (`!info`):** Sahip olduğunuz Pokémon'un adını, canını ve gücünü istediğiniz an kontrol edersiniz.
* **Kapsamlı Savaş Sistemi (`!attack`):** Farklı sınıflara (`Fighter`, `Wizard`) sahip Pokémon'larla kapışmalar yapabilirsiniz!
* **Sıfırlama (`!reset`):** İstediğiniz zaman Pokémon'unuzu silip baştan başlayabilirsiniz.

---

## 🎮 Komutlar

| Komut | Açıklama |
| :--- | :--- |
| `!go` | Size rastgele özelliklerde ve görselde yeni bir Pokémon verir. |
| `!info` | Mevcut Pokémon'unuzun durumunu ve resmini gösterir. |
| `!reset` | Mevcut Pokémon'unuzu siler, yenisini almanıza olanak tanır. |

---

## 🛠️ Kullanılan Teknolojiler

* **Python** 🐍
* **discord.py** (Discord Bot Kütüphanesi)
* **PokeAPI** (Pokémon verileri ve görselleri için)
* **aiohttp** (Asenkron HTTP istekleri)
